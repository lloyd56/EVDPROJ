
# PrintEase Website

## Project Description
PrintEase is an affordable printing and school supplies
website designed for students, teachers, and school organizations.

5. Daniel Racho - About page and contact form
6. Recapente - CSS styling, README, and final testing

## How to Run
1. Save all HTML files in one folder.
2. Save style.css and script.js in the same folder.
3. Open index.html in a web browser.
4. Click the navigation links to visit each page.
5. Test the order form and printing calculator.

## Final Testing
- [ ] All six HTML pages open correctly.
- [ ] All navigation links work.
- [ ] The order total updates correctly.
- [ ] The calculator supports B&W and colored printing.
- [ ] The quantity controls work.
- [ ] The contact form validates required fields.
- [ ] The layout works on mobile and desktop.

## Important Note
The order and inquiry forms are demonstrations.
A backend is required to save orders or send messages.
